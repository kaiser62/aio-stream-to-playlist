# Companion for TorBox (working name)

Native app (Tauri 2 / Rust) for macOS, Windows, Linux, iOS and Android: manage any Stremio-compatible addons,
filter their results, send to TorBox and build playable `.m3u8` playlists (IINA, VLC, mpv, Infuse).
Unofficial; not affiliated with TorBox or Stremio.

Status: in development. See `legacy/` for the working Python/web prototype.
